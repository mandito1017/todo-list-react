Todo List React

Aplicación web para gestionar tareas y metas personales, con fecha límite para cada tarea.

Tecnologías utilizadas

- React 18
- React Bootstrap 2.10
- Bootstrap 5
- CSS externo por componente

Estructura del proyecto
src/
├── App.js
├── App.css
├── components/
│   ├── Header.jsx / Header.css
│   ├── TaskForm.jsx / TaskForm.css
│   ├── TaskList.jsx / TaskList.css
│   └── TaskItem.jsx / TaskItem.css

 Cómo ejecutarlo localmente

1. Clona el repositorio:https://github.com/mandito1017/todo-list-react.git
2. Entra a la carpeta
3. Cambia a la rama Semana 1
4. Instala dependencias Npm Install
5. Inicia el proyecto Npm Start
6. Abre tu navegador en http://localhost:3000/

Funcionalidades

- Agregar tareas con título, meta asociada y fecha límite
- Marcar tareas como completadas
- Eliminar tareas
- Contador de tareas totales, pendientes y completadas
- Diseño responsive con React Bootstrap
